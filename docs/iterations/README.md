# 项目迭代方案

本目录用于记录项目的迭代设计方案。方案文档纳入 Git 版本管理，并随项目代码提交到 GitHub 仓库。

## 命名规范

- 文件名格式：`NNN-主题.md`
- `NNN` 使用三位递增序号，例如 `001`、`002`、`003`
- 每个迭代方案独立成文，已经发布的序号不重复使用
- 新增方案后同步更新本索引
