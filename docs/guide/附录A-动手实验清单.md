# 附录 A 动手实验清单

这是全书「动手试一试」的索引。实验的**正文和真实输出都在各章里**，这里只回答三个问题：

- 有哪些实验？
- 每个实验想让你看见什么？
- 我现在手上有什么条件（有没有 API Key、有没有半小时），该做哪几个？

所有实验都在 `HEAD = e7d1113` 上真实执行过。**绝大多数不需要 API Key** ——
这不是巧合，是这个项目刻意把设备层、工具层、路由层、检索层都做成了不碰模型的纯代码，
第 17 章讲了为什么这个边界值得你在自己的项目里也划一遍。

## 通用前置

```bash
# 所有命令都在项目根目录下跑
cd "G:/大厂学习/minimind/langgraph"

# Python 解释器固定用这个 Conda 环境，不要 uv、不要新建 .venv
F:/Software/Anaconda/envs/langgraph/python.exe

# Windows 下任何会打印设备名或 emoji 的命令都要加 PYTHONIOENCODING=utf-8
PYTHONIOENCODING=utf-8 F:/Software/Anaconda/envs/langgraph/python.exe -m pytest -q
```

写着「Python 片段」的实验，都可以塞进 `python -c "..."`，
或者更舒服的办法：存成一个临时 `.py` 文件再跑。片段开头那句
`from loguru import logger; logger.remove()` 是关日志噪音用的，不加也能跑，只是屏幕会脏。

## ⚠️ 会改到项目代码的实验

上表里标了 ⚠️ 的，会让你临时改 `src/` 或 `tests/`。做之前先确认工作树是干净的：

```bash
git status --short          # 应该只有你自己的改动
git stash list             # 确认没有忘掉的暂存
```

做完之后：

```bash
git diff                                    # 看清自己改了什么
git checkout -- <改过的文件>                 # 或者手工改回来
PYTHONIOENCODING=utf-8 F:/Software/Anaconda/envs/langgraph/python.exe -m pytest -q
# 必须回到绿色基线，否则你留下了一个自己制造的 bug
```

这份"改坏 → 看症状 → 改回来 → 确认绿"的循环本身就是练习。
第 17 章讲的就是这件事：**你判断改动有没有改坏东西的手段，比改动本身重要。**

## 三条练习路线

**A. 半小时快跑**（只想有个手感）

1. `0.3` 跑通测试和 `status`
2. `2.4 实验 A` 打印图结构
3. `3.4 实验 B` 撞一次"拒绝猜测"
4. `4.4 实验 B` 绕过 LLM 直接调工具
5. `10.4 实验 A` 撞一次 `InvalidUpdateError`

这五个都不需要 API Key，跑完你就理解了"图 + 工具 + 状态"这三件事。

**B. 一天精读**（推荐）

顺着章号做。每章的实验做完之后，回头看那一章的 `N.5 踩坑与局限` ——
**实验让你看见机制，踩坑告诉你机制在哪里不够。**

特别不要跳过这三个：

- `7.4 实验 B`（暂停跨进程存活）—— 它把 Checkpoint 从概念变成了肌肉记忆
- `11.4 实验 B`（找出没人看得见的工具）—— 它会当场找出一个真实缺陷
- `17.4 实验 D`（加一台香薰机）—— 它把前十六章串成一条完整的改代码流程

**C. 改代码前的回归自查**

```
1. 17.4 实验 A          先拿到绿色基线
2. 改你的代码
3. pytest -q            对比基线，看多了哪些红
4. 3.4 实验 D           如果动了 capabilities.py，看派生对不对
5. 11.4 实验 B          如果加了非设备工具，看有没有角色能看见它
6. 15.4 实验 B          如果动了观测代码，确认三条通道还在写
7. 第 18 章 18.4        照那 8 个问题过一遍
```

## 这个附录的局限

这里只有**索引**，没有实验正文。这是刻意的：正文和真实输出跟着章节走，
才不会出现"附录里的输出和章里的输出不一致"这种最难维护的状态。

另外，实验覆盖的是**已经想到的**那些机制。真正的收获往往来自你自己乱改一通之后
撞出来的东西 —— 那时候翻[附录 B](附录B-常见报错速查.md)。
