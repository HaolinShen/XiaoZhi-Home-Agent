# SilkRail C100 常见症状排查

## 开合到一半停住

1. 确认窗帘主机处于通电开机状态，断电时不响应任何指令。<!--check:device_is_on-->
2. 确认窗帘当前不在完全关闭位置，已闭合到位属于正常终点。<!--check:curtain_not_fully_closed-->
3. 检查导轨内有无异物，以及帘布是否卡在滑轮之间。<!--manual-->
4. 重新标定行程，端点记录偏移会让帘布提前停下。<!--manual-->

## 遥控无响应

1. 确认主机处于通电开机状态，主机断电时遥控自然无效。<!--check:device_is_on-->
2. 更换遥控器电池，电量不足时发射距离会明显缩短。<!--manual-->
3. 确认遥控器与主机的配对信息未丢失，必要时重新配对一次。<!--manual-->
4. 缩短操作距离，避开承重墙与金属家具遮挡后重试。<!--manual-->

## 帘布褶皱不均

帘布收合后出现均匀的竖向褶皱是布料悬垂特性带来的正常外观。褶皱明显不均或帘布向一侧堆积时，多为吊环间距不一致或部分滑轮脱出导轨。请断开主机供电后手动推动帘布，逐个确认滑轮是否都在轨道内、吊环挂钩有无脱扣，并把吊环沿导轨重新均分。新安装的帘布悬挂一周左右会自然回复平整，不要用熨斗直接接触面料。导轨中段下垂同样会造成跑偏，需增加吊装支架。
