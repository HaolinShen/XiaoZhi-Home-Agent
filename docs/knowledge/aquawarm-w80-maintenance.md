# AquaWarm W80 保养与清洁

## 清洁周期

建议每月检查一次安全阀泄压小孔是否通畅，每季度清理花洒滤网与进水口过滤网。水质硬度较高的地区应每一至两年做一次内胆排污除垢，并同期检查镁棒。外壳只需用微湿软布擦拭，切勿冲洗电气盒与接线端子。

## 内胆除垢步骤

先关闭机身电源开关与专用断路器，关闭进水阀，打开热水龙头与安全阀手柄泄压排水，确认内胆存水排尽、水温降至常温后再动手。取下法兰盖，清除内胆底部垢渣与加热管表面垢层，避免刮伤搪瓷内壁。回装时更换法兰密封圈，务必先注满水再通电，空烧会立即烧毁加热管。

## 镁棒检查与更换

镁棒是牺牲阳极，直径腐蚀过半即应更换，通常一至两年检查一次，水质差时缩短周期。检查前的断电、关阀、泄压排水步骤与除垢完全相同。取出时记录原有规格与螺纹尺寸，必须换装同规格原厂件；缺装镁棒会让内胆在一两年内穿孔漏水。装回后确认密封无渗漏再恢复通电。
