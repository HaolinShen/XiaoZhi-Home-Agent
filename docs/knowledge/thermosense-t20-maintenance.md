# ThermoSense T20 保养与清洁

## 电池更换

正常采样周期下电池续航约为一年，面板提示电量偏低后应尽快更换，避免因电压不足造成读数漂移或链路重试频繁。更换前请先将设备从底座取下，用绝缘工具轻推电池仓弹片取出旧电池，切勿使用金属镊子直接跨接两极。装入新电池后合紧后盖，设备会在数十秒内完成自检并重新入网。旧电池请按有害垃圾分类投放。

## 探头清洁

温湿度探头外罩为透气滤网，每半年应清理一次。清理时先断电取下电池，再用软毛刷沿滤网纹路轻扫表面浮尘，或用干燥的压缩空气短促吹拂。严禁用水、酒精、清洁剂冲洗，也不要用棉签深入探头腔体触碰感湿膜，任何液体与机械摩擦都会破坏校准特性。清理完成后静置片刻再通电，确认无残留湿气。

## 安装位置建议

设备应安装在离地一米二左右、能代表房间平均环境的墙面上，避开阳光直射、空调与地暖出风口、门窗缝隙以及电视、路由器等发热设备。与 Zigbee 网关的直线距离建议不超过五米，中间尽量不隔承重墙或金属柜体。切勿贴装在瓷砖背后或嵌入吊顶夹层，屏蔽会让链路频繁中断，同时也无法反映真实的居住体感。
