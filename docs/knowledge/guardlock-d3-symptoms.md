# GuardLock D3 常见症状排查

## 指纹识别成功率下降

1. 确认门锁处于在线通电状态，离线或断电时指纹通道不会响应。<!--check:device_is_on-->
2. 确认电池电量未偏低，低压时采集头供电不稳会明显拉低识别率。<!--check:device_battery_not_low-->
3. 清除指纹采集头表面的油污、汗渍与灰尘，用干燥软布擦拭，切勿用酒精浸泡。<!--manual-->
4. 检查录入的手指是否干裂、脱皮或有伤口，必要时补录同一手指的多个角度。<!--manual-->

## 开锁后未自动上锁

1. 确认门锁处于在线通电状态，断电时自动上锁不会执行。<!--check:device_is_on-->
2. 确认电池电量未偏低，省电模式会主动停用自动上锁以保留开门电量。<!--check:device_battery_not_low-->
3. 确认门扇已完全闭合，斜舌未完全压入锁孔时锁体会判定为门未关闭。<!--manual-->
4. 检查把手虚位是否变大、锁点与锁孔是否错位，必要时请售后调整合页与导向片。<!--manual-->

## 按键无响应

触摸键盘待机时不亮，需先以手掌覆盖或轻触面板唤醒，唤醒后数字键才会点亮，这是省电设计而非故障。整片按键均无反应时，先取下电池仓盖检查电池是否装反、触片有无氧化生锈，并整组更换新电池。面板长期日晒雨淋后可能受潮，可静置干燥后重试。仍无响应请用机械钥匙进门并联系售后更换面板，不要用尖硬物敲击按键。
