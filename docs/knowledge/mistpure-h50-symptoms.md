# MistPure H50 常见症状排查

## 雾量明显偏小

1. 确认加湿器处于开机状态，待机状态下换能片不工作，不会产生雾气。<!--check:device_is_on-->
2. 确认水箱内仍有水，水位低于下限时换能片会被保护性切断。<!--check:humidifier_tank_has_water-->
3. 检查换能片表面是否结垢，水垢会显著削弱超声波雾化效率。<!--manual-->
4. 检查出雾口与导雾管有无堵塞，并确认水箱底阀已压紧、进水通畅。<!--manual-->

## 湿度长时间不上升

1. 确认加湿器处于开机状态，仅设置目标湿度不会启动雾化。<!--check:device_is_on-->
2. 确认目标湿度高于实测室内湿度，目标值偏低时机器达标即停机。<!--check:humidifier_target_above_room-->
3. 检查房间门窗是否敞开或存在强对流，湿气外泄会使湿度长期停在低位。<!--manual-->
4. 检查湿度传感器窗口是否积尘，读数虚高会让机器提前停止雾化。<!--manual-->

## 机身底部渗水

底座周围出现少量凝水，多为雾气在低温台面遇冷液化，属正常现象，可垫吸水软垫并移至通风处。持续积水应先断电、倒空水箱，检查水箱密封圈是否老化变形、底阀是否被水垢顶起而无法回位。注水超过最高水位线时也会经溢流口外渗。机身放置不平会使底座水槽单侧溢出，请置于平整硬质台面。渗水原因未查明前不要通电运行。
