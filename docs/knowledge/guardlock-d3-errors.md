# GuardLock D3 故障代码

## E1

E1 表示指纹模组通信失败，主控读不到采集头上报的数据，此时指纹通道不可用。请改用密码或机械钥匙进门，先取下电池仓盖、重新插拔一次电池完成复位。复位后仍报此码，多为前面板排线松脱或采集头损坏，应联系售后检修，切勿自行拆卸面板扯动排线。

## E2

E2 表示电池电压过低，剩余电量已不足以稳定驱动离合器与电机开锁，门锁会进入省电模式并持续提示。请尽快按电池更换流程整组换新，不要新旧电池混用或与碳性电池混装。低压期间不要反复重试开锁，电机堵转可能停在半开位，务必随身携带机械钥匙。

## 1003

1003 表示连续多次验证失败，门锁已进入锁定状态，在锁定时长内拒绝一切指纹与密码尝试，这是防试探的正常保护。请等待锁定自动解除，期间反复尝试会重新计时；急需进门时使用机械钥匙。若无人尝试却频繁出现此码，应检查采集头是否被雨水或异物持续误触发，并调取开锁记录核对。

## 保修说明

整机保修两年，锁体机械部件保修三年，起始日期以购机凭证为准。自行拆解锁体、改动电路或使用非原厂配件导致的故障不在保修范围内。电池属易损耗材，不享受保修。报修时请提供型号 GuardLock-D3、锁体机身条码和面板显示的故障代码，并说明机械钥匙是否仍能正常开启。
