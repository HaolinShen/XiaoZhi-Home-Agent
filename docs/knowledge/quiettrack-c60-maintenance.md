# QuietTrack C60 保养与清洁

## 导轨与滑轮保养

静音效果依赖滑轮与导轨的良好配合，建议每季度清理一次导轨内的积尘与毛絮。清理前断开主机供电，用吸尘器细嘴配合软毛刷处理，滑轮轮轴干涩时点少量硅脂。不要使用喷雾式润滑油，油雾会附着在同步带齿面上造成打滑。清理后手动推动窗帘，阻力均匀且无卡滞即为正常。

## 同步带与机芯保养

每年检查一次同步带的齿面磨损与张力：齿面发亮、出现裂纹或缺齿时须整根更换原厂配件，不要截短接续；张力以按压中段略有形变为宜，过紧会加剧导轨磨损并抬高运行噪音。机芯为免维护密封结构，禁止自行拆开，拆解会破坏减振垫与静音腔的装配精度，复装后噪音明显增大。任何检查前务必先断开供电。

## 长期不用时的存放

长期离家前把窗帘停在完全打开位置，避免布面同一折痕处长时间受阳光直射产生色差，并断开主机适配器电源。重新启用时先送电让主机与网关完成校时，再空载运行一次全程，观察有无异响。停用超过半年后建议清理一次导轨，并检查适配器线材有无被挤压变形。
