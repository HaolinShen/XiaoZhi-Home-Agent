# LumiCore L200 常见症状排查

## 调光不连续

1. 确认筒灯处于开机状态，待机时调光指令不会生效。<!--check:device_is_on-->
2. 确认亮度设置不为 0，最低档附近的可视变化本身很小。<!--check:light_brightness_not_zero-->
3. 检查调光信号线端子是否压接到位，接触不良会造成跳档。<!--manual-->
4. 确认同一驱动器带载的筒灯数量未超出额定范围。<!--manual-->

## 局部筒灯不亮

1. 确认该照明回路处于开机状态，整组关闭时单灯自然不亮。<!--check:device_is_on-->
2. 确认亮度未被调至 0，调光值过低时单灯看起来近似熄灭。<!--check:light_brightness_not_zero-->
3. 检查不亮筒灯的快接端子有无松脱、油污或氧化。<!--manual-->
4. 与相邻正常筒灯对调驱动器，判断故障在驱动侧还是灯板侧。<!--manual-->

## 灯体表面温度偏高

筒灯工作时外壳与散热齿片温度明显高于室温，属于 LED 驱动的正常散热表现。厨房吊顶空间狭小时应确认开孔尺寸符合安装要求，孔径过小会阻碍对流散热；灯体周围不要填塞保温棉或包裹装饰材料，长期高温运行会加速光衰并缩短驱动器寿命。油污附着在散热齿片上同样会降低散热效率，清洁前须断开照明回路并等灯体完全冷却。外壳出现变形、发黄或塑料焦糊气味时立即断电停用并联系售后。
