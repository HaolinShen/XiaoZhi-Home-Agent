# ThermoSense T20 故障代码

## E1

E1 表示温湿度探头开路。主控在采样周期内连续读取到超量程的阻值，判定探头引线断开、插接件松脱或探头本体损坏。请断电后检查探头排线是否完整插入主板插座，插针有无氧化发绿。若重新插接后代码仍在，说明探头已失效，需整体更换探头组件，不可只补接引线，否则校准偏移无法复现出厂值。

## E2

E2 表示电池电压过低。电池输出已降至采样电路的最低工作阈值以下，此时温湿度读数会出现系统性漂移，无线上报也可能间歇丢包。请更换同规格纽扣电池，注意正负极方向，避免用混合品牌或新旧混用的电池。更换后设备会自动重新采样，若代码在数分钟内未消除，请检查电池仓弹片有无锈蚀。

## E6

E6 表示无线链路长时间中断。设备在多个上报周期内未收到 Zigbee 网关的应答，已进入低频重试状态。常见原因是网关掉电、信道被邻近设备占用，或传感器与网关之间的直线距离超过五米且中间隔有承重墙。请先确认网关工作正常，再将传感器移近网关或加装中继节点，必要时重新入网。

## 保修说明

本机整机保修两年，温湿度探头组件保修一年，电池等易损耗材不在保修范围。人为拆解、液体浸泡、超量程环境使用导致的损坏视为非保修故障。报修时请提供设备型号与机身背面的机身条码，两项信息缺一无法建档；建议同时提供故障代码与首次出现时间，可显著缩短检测周期。
