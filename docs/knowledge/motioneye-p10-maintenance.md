# MotionEye P10 保养与清洁

## 探头清洁

菲涅尔透镜表面积尘会削弱红外聚焦效果，直接缩小有效探测角度，建议每半年清洁一次。清洁前先取下电池断电，用干燥的镜头布或软毛刷沿透镜弧面单向轻擦，避免打圈摩擦造成细密划痕。严禁使用酒精、香蕉水等有机溶剂，溶剂会腐蚀透镜的聚乙烯材质，也不要用尖锐物撬开透镜罩探入内部擦拭元件。

## 电池更换

在默认驻留超时与常规触发频次下，电池续航约为一年，指示灯出现规律慢闪即提示电量偏低。更换时先从磁吸底座取下机身，按电池仓箭头方向推开后盖，用绝缘工具取出旧电池，切勿用金属工具跨接两极造成短路。装入新电池时对准正负极标识，合盖后设备自检并自动重连网关，无需重新配网。旧电池按有害垃圾投放。

## 安装位置建议

建议将设备安装在离地两米二左右的墙角，探测面朝向人员横向经过的通道，而不是正对人直线走来的方向，这样能获得最大的有效探测角度。应避开空调出风口、暖气片、直射阳光以及正对玻璃门与大面积镜面的位置，避免热气流与红外反射造成误触发。使用磁吸底座时先确认墙面平整干燥，粘贴后静置一日再挂机身。
