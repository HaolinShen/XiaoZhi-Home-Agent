# QuietTrack C60 故障代码

## E2

E2 表示电机堵转过流保护，运行电流超过阈值后主机立即停转，以免电机绕组过热损坏。请先切断主机供电，检查轨道内有无异物、窗帘是否卡在滑轮之间，窗台摆件顶住布面或纱帘缠绕都是同类常见诱因。手动推动滑轮组感受阻力，阻力偏大时先清理轨道，再空载试运行一次。空载状态下仍报出该代码，通常是减速齿轮或电机轴承卡滞，须联系售后更换机芯。

## E6

E6 表示霍尔位置传感器信号丢失，主机收不到转动计数，无法判断窗帘走到了哪里，只能停止运行。请断电后重新送电，让主机重新读取传感器。若代码持续存在，多为传感器排线松脱或受潮氧化，应联系售后检查机芯内部排线。不要自行拆开机芯外壳，拆解会破坏静音结构的密封与减振垫，复装不到位会明显增大运行噪音。

## 118

118 表示直流电源适配器输出欠压，供电不足时电机可能中途停转或完全不动作。请确认使用的是原厂适配器、插头已插紧，并避免与大功率电器共用同一排插。冬季低温环境下适配器输出略有下降属正常现象，但持续欠压需更换适配器。更换前先从插座侧断电，不要带电插拔机芯电源接口。

## 保修说明

机芯与静音电机整机保修三年，适配器、同步带、滑轮与减振垫等易损件保修一年；自行拆解机芯、使用非原厂适配器或窗帘超出额定载重导致的故障不在保修范围内。报修请提供型号 QuietTrack-C60、机芯侧面的序列号与当前故障代码，并说明故障是否可复现。上门检修前请先断开主机供电。
