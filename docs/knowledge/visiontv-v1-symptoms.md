# VisionTV V1 常见症状排查

## 画面正常但无声音

1. 确认电视处于开机状态，待机唤醒不完全时会先出画面、音频通道尚未初始化。<!--check:device_is_on-->
2. 确认当前未处于静音状态，静音图标可能因界面自动隐藏而不易察觉。<!--check:tv_is_not_muted-->
3. 核对音频输出设置，若曾接过外部音响，输出可能仍锁定在 ARC 或光纤通道而非机内扬声器。<!--manual-->
4. 更换一路 HDMI 接口并重新插紧线缆，接触不良或不支持 ARC 的接口会导致只出图像不出声。<!--manual-->

## 遥控无响应

1. 确认电视本体已开机，若整机处于断电状态，遥控的任何按键都不会有反馈。<!--check:device_is_on-->
2. 更换遥控电池并确认正负极方向正确，电压偏低时红外发射距离会急剧缩短。<!--manual-->
3. 清理电视下沿的红外接收窗，遮挡物、贴膜或摆件都会阻断信号；同时避免强光直射接收窗。<!--manual-->
4. 若使用蓝牙遥控，请长按配对键重新配对，固件升级后配对信息可能失效。<!--manual-->

## 网络视频频繁缓冲

网络视频反复缓冲多为带宽与链路质量问题，而非屏幕或解码故障。请先在设置中查看网络测速结果，确认下行带宽是否满足当前清晰度；随后将电视改用有线网口直连路由，或把无线连接切换到 5 GHz 频段以避开拥塞信道。同时确认固件与视频应用均为最新版本，并清理应用缓存。若仅个别平台卡顿，通常是该平台的内容分发节点问题，可稍后重试或降低播放清晰度。
