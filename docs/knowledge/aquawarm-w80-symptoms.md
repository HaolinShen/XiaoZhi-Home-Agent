# AquaWarm W80 常见症状排查

## 出水温度偏低

1. 确认热水器处于开机通电状态，断电时段内不会加热内胆存水。<!--check:device_is_on-->
2. 确认设定水温足够高，设定值偏低时温控器达标即停止加热。<!--check:water_heater_target_is_high_enough-->
3. 检查花洒前的混水阀是否偏向冷水侧，混水比例失调会明显拉低出水温度。<!--manual-->
4. 检查内胆结垢情况，垢层包裹加热管会大幅削弱换热效率。<!--manual-->

## 加热时间明显变长

1. 确认热水器处于开机通电状态，中途断电会让升温进度归零重新开始。<!--check:device_is_on-->
2. 检查内胆与加热管表面的垢层厚度，水垢导热极差，会成倍拉长升温时间。<!--manual-->
3. 检查镁棒余量，镁棒耗尽后腐蚀产物沉积在内胆底部，同样阻碍换热。<!--manual-->
4. 检查进水温度，冬季自来水偏冷时升温耗时本身就会明显增加。<!--manual-->

## 出水有异味或浑浊

长期停用后首次放水略显浑浊或带轻微金属味，多为内胆底部沉积的水垢与镁棒腐蚀产物被水流搅起，持续放水数分钟即可转清。若异味长期不散或水色发黄发黑，说明结垢与腐蚀已较严重，应断电、关闭进水阀并泄压排水后按保养要求彻底排污除垢，同时检查镁棒。出现明显硫化物臭味时不要饮用，并联系售后检查内胆状况。
