# SilkRail C100 故障代码

## E2

E2 表示行程未标定，主机尚未记录全开与全闭两个端点的位置，因此只接受点动运行而拒绝按百分比开合的指令。首次安装、长时间断电或更换帘布长度后都需要重新标定：按住主机标定键直至指示灯慢闪，让帘布走到完全闭合位置确认一次，再走到完全打开位置确认一次，指示灯转为常亮即完成。标定期间不要用手拉动帘布，否则记录的端点会偏移。

## E7

E7 表示同步带张力不足，皮带在驱动轮上出现打滑，位置反馈与帘布实际位置逐渐累积偏差。请断开主机供电后检查同步带有无油污、齿面是否磨损发亮，并按张紧螺栓标识的扭矩重新张紧；张力过大则会加剧导轨磨损与运行噪音。调整后重新标定一次行程。同步带出现裂纹或缺齿必须整根更换原厂配件，不要截短接续使用。

## 204

204 表示遥控器与主机的配对信息丢失，此时主机本体按键与应用端指令仍可正常控制窗帘。请在主机通电状态下短按配对键至指示灯快闪，再按住遥控器的开启键直至指示灯回落为常亮，即完成重新配对。多个房间使用同型号遥控器时逐台配对，避免串控。反复丢失配对信息通常是主机存储模块异常，应联系售后。

## 保修说明

主机与电机整机保修两年，同步带、滑轮、限位组件等易损件保修一年；自行拆解、使用非原厂配件或帘布超出额定载重导致的损坏不在保修范围内。报修时请提供型号 SilkRail-C100、主机铭牌上的序列号以及当前故障代码，可显著缩短上门排查时间。主机安装位置较高时请由售后人员使用专业梯具作业，不要自行攀爬拆卸，并在检修前断开供电。
