# LumiCore L200 保养与清洁

## 清洁周期

厨房油烟对筒灯面板与散热齿片的影响显著，建议每月检查一次，油污附着明显时立即清洁；开放式厨房或经常爆炒的家庭缩短至每两周一次。散热齿片积油会直接降低散热效率，长期高温运行既加速光衰，也会缩短驱动器寿命。

## 清洁步骤

清洁前断开照明回路的断路器并验电，等灯体完全冷却后操作，嵌入式筒灯刚熄灭时外壳温度较高。用中性厨房清洁剂稀释后润湿柔软棉布擦拭面板与外圈，不要让液体流入灯体内部或接线端子。散热齿片上的油污用软毛刷配合少量清洁剂清除，禁止直接冲水。全部部位彻底干燥后再恢复送电。

## 驱动器检查

每年检查一次驱动器的安装状况：确认吊顶内没有被保温棉包裹、接线端子无发黑氧化、快接头压接牢固，检查须在断电验电后进行。驱动器外壳变形、鼓包或散发焦糊气味时立即停用，并更换原厂同规格产品；输出电流不匹配会造成各筒灯亮度不一致，并使灯板提前光衰。
