# VisionTV V1 保养与清洁

## 屏幕清洁

清洁屏幕前必须关机并拔下电源，待面板完全冷却后再操作，带电擦拭有触电与静电击伤面板的风险。请使用干燥柔软的超细纤维布，从屏幕中央向外单向轻擦，切勿打圈用力按压，液晶层受压会留下不可恢复的亮斑。严禁喷洒清水、玻璃水、酒精或含氨清洁剂，液体渗入边框会腐蚀导电膜。屏幕边框缝隙的浮尘可用软毛刷轻扫。

## 接口与线缆检查

建议每半年检查一次机背接口。断电后逐一确认 HDMI 线缆插头是否插到位、卡口有无松动，接触不良往往先表现为间歇黑屏或 ARC 回传失效。用软毛刷清理接口内的积尘，切勿用金属物捅入针脚。若使用壁挂安装，请顺势检查线缆是否被过度弯折或受墙面挤压，弯折半径过小会造成内部铜线断裂。

## 散热与固件维护

电视背部散热孔积尘会抬高整机温度并加速背光衰减，请每季度断电后用软毛刷或吸尘器低吸力清理散热孔，注意不要让刷毛探入内部。壁挂或嵌入柜体安装时须在机背留出足够空隙，切勿用装饰布遮盖散热孔。系统固件建议保持自动更新，升级过程中不要断电或拔插电源，中断升级可能损坏系统分区。
