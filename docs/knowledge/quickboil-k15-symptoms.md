# QuickBoil K15 常见症状排查

## 加热中途停止

1. 确认电热水壶处于开机通电状态，底座断电或插座松动都会中断加热。<!--check:device_is_on-->
2. 确认壶内水量在最低与最高刻度线之间，水量不足会触发干烧保护。<!--manual-->
3. 检查壶体是否完全落座，搬动或倾斜使触点瞬断时加热会自动停止。<!--manual-->
4. 检查壶盖是否盖严，蒸汽无法到达感温口时沸腾判定会提前结束加热。<!--manual-->

## 烧水时间明显变长

1. 确认电热水壶处于开机通电状态，未启动加热时只显示水温而不升温。<!--check:device_is_on-->
2. 确认目标水温已设到沸点，设定值偏低时到温即停，并非故障。<!--check:kettle_target_is_boiling-->
3. 检查壶底加热盘的垢层厚度，水垢导热极差，会明显拉长烧水时间。<!--manual-->
4. 检查一次注水量是否偏多，水量接近最高刻度线时耗时自然增加。<!--manual-->

## 壶底结垢严重

水垢主要来自自来水中的钙镁离子，硬水地区结垢更快，壶底出现白色或灰白色硬壳属常见现象。垢层会削弱导热、拉长烧水时间，并可能让沸腾判定失准。请按除垢步骤定期处理，切勿用钢丝球或金属铲刮擦，划痕会加速新垢附着并损伤加热盘涂层。每次用完倒尽余水、敞盖晾干，可明显减缓结垢速度。
