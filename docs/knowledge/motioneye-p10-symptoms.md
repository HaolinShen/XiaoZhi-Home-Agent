# MotionEye P10 常见症状排查

## 有人时未触发

1. 确认设备处于开机上线状态，离线期间不会产生任何存在事件上报。<!--check:device_is_on-->
2. 确认电池电量未偏低，电压不足时热释电前级放大的灵敏度会明显下降。<!--check:device_battery_not_low-->
3. 检查菲涅尔透镜表面是否被灰尘、油膜或贴纸遮挡，透镜受遮挡会直接压缩探测角度。<!--manual-->
4. 核对安装高度与朝向，探头对垂直于探测面的横向移动最敏感，正对通道直走的人体最易漏检。<!--manual-->
5. 确认目标是否处于长时间静坐状态，热释电只响应红外热源的变化量，完全静止的人体可能不产生新事件。<!--manual-->

## 无人时频繁误触发

1. 确认设备仍在正常上线状态，反复掉线重连时会在恢复瞬间补报一次存在事件。<!--check:device_is_on-->
2. 确认电池电量未偏低，欠压会让前级放大出现随机跳变，表现为无规律误报。<!--check:device_battery_not_low-->
3. 检查探测范围内是否有空调出风口、暖气片、加湿器或飘动的窗帘，流动的热气流与运动物体都会被判为热源变化。<!--manual-->
4. 排查是否有宠物在探测区域活动，并确认镜面、玻璃门是否把邻室的热源反射进探测角度内。<!--manual-->

## 状态恢复延迟偏长

存在状态由无人恢复为空置的时间由驻留超时决定，出厂值偏保守，因此在人已离开后仍会维持一段占用状态。若延迟明显偏长，请检查是否在网关侧把驻留超时调大，或有自动化规则在反复刷新占用状态；同时确认探测角度内没有持续变化的热源，例如常开的电暖器或阳光缓慢移动照射的地面，这类持续扰动会不断续期超时，看起来像状态迟迟不恢复。
