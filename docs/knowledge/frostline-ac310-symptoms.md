# FrostLine AC310 常见症状排查

## 制冷效果不佳

1. 确认空调处于开机运行状态，机组待机时压缩机不会投入工作，仅面板有显示。<!--check:device_is_on-->
2. 核对运行模式是否为制冷，送风与除湿模式下压缩机不按制冷负荷运转，室温不会明显下降。<!--check:ac_mode_is_cool-->
3. 核对设定温度是否低于当前室温，设定值高于室温时机组判定已达标并停止制冷输出。<!--check:ac_target_temp_below_room-->
4. 核对风速档位，长期停在最低档会使蒸发器换热量不足，冷量积在机内难以送达房间深处。<!--check:ac_fan_speed_not_lowest-->
5. 检查滤网积尘程度与室外机散热片是否被杂物遮挡，进出风受阻会同时拉低制冷量。<!--manual-->

## 排水不畅

1. 确认空调处于开机状态，停机期间接水盘不再产生新的冷凝水，故障现象会被暂时掩盖。<!--check:device_is_on-->
2. 核对运行模式是否为制冷或除湿，只有蒸发器温度低于露点时才会持续凝水，据此判断渗漏时机。<!--check:ac_mode_is_cool-->
3. 检查冷凝水管走向是否全程向下倾斜，管路被家具压住、上翘或折弯都会让积水回流至接水盘。<!--manual-->
4. 排查排水管末端有无泥沙、絮状物或虫巢堵塞，可拆下末端接头疏通；拆装前务必断电。<!--manual-->

## 蒸发器结霜

蒸发器表面结霜多由换热量不足或制冷剂循环异常引起。滤网严重积尘、风速长期偏低会使流过蒸发器的风量不足，盘管温度降至冰点以下而结霜；制冷剂偏少或毛细管局部堵塞时，蒸发压力过低同样会在进液侧先结霜。请先断电，待霜层自然融化后清洗滤网并恢复中高风速运行观察。若结霜反复出现或伴随出风温度回升，属于制冷系统问题，需由专业人员检测制冷剂压力与毛细管通畅情况，请勿自行开阀补充制冷剂。
