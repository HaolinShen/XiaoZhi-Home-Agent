# LumiCore L200 故障代码

## E1

E1 表示调光信号线接触不良，控制器发出的 PWM 调光指令无法完整送达驱动器，表现为亮度停在某一档、跳档或调光过程中闪断。请先关闭照明回路的断路器并验电，再检查筒灯与调光器之间的信号线端子是否压接到位、线芯有无氧化发黑、正负极线序是否与标识一致。多路筒灯串接时逐个复位快接头，重新送电后从最低档缓慢调至最高档观察是否恢复。端子完好而代码仍在，应联系售后检测调光器输出。

## F2

F2 表示输入电压超出额定工作范围，驱动器为保护灯板而停止输出。厨房与大功率电器共用回路时，电饭锅、微波炉启动瞬间的电压跌落容易触发该保护。请观察代码是否只在特定电器启动时出现，若是，应把照明回路与大功率插座回路分开。长期欠压或过压需请电工检测配电箱与回路导线截面，不要在灯具侧串接非原厂稳压模块。

## 1015

1015 表示固件升级包校验失败，升级已自动回滚，筒灯仍按升级前的版本正常工作。请确认网络连接稳定后重新发起升级，升级过程中不要断开灯具供电。连续多次校验失败通常是下载通道异常，等待厂商发布新的升级包即可。不要通过第三方渠道刷入固件，版本不匹配会导致灯具无法启动。

## 安全提醒

检查信号线端子、更换驱动器或改动回路接线前，必须先断开照明回路的断路器并验电，厨房环境潮湿，带电操作风险更高。取下嵌入式筒灯时注意灯体余温，刚熄灭时外壳温度较高。智能体只能给出说明书范围内的排查建议，不能确认硬件已经修好；驱动器与调光器是否损坏须由专业人员现场检测判定。
