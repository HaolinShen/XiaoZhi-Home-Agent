# FrostLine AC310 故障代码

## E4

E4 表示排水异常，排水泵未能正常排出冷凝水。请检查室内机排水管是否弯折、上翘或末端浸入积水，管路不畅时冷凝水会回流至机内。取下面板清理冷凝水盘中的灰泥和杂物，并确认排水口没有被絮状污物封住。水盘水位过高会触发溢水保护并停止制冷，这是正常的保护动作，不要反复强制开机。清理后断电重启，若代码仍未消失，说明排水泵或水位开关可能故障，应联系售后。

## E7

E7 表示室内风机转速异常，实测转速与设定值持续不符，常伴随风量忽大忽小或完全无风。请关机断电，确认出风口和贯流风扇未被异物卡住，清除风道内杂物后重新上电。扇叶长期积尘结垢也会拖慢转速，可按保养要求清理表面浮尘。若代码反复出现，风机电机或驱动模块可能已损坏，需由售后更换，不要自行拆卸风扇叶轮。

## 保修说明

整机保修两年，压缩机及制冷系统主要部件保修六年，起始日期以购机凭证为准。自行拆机、改动电气线路或使用非原厂配件导致的故障不在保修范围内。滤网、遥控器电池等易损耗材不享受保修。报修时请提供型号 FrostLine-AC310、机身条码和屏幕显示的故障代码。
