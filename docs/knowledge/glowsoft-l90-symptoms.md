# GlowSoft L90 常见症状排查

## 亮度明显偏低

1. 确认灯具处于开机状态，待机状态下不会输出照明。<!--check:device_is_on-->
2. 确认亮度设置不为 0，调光值过低时肉眼近似熄灭。<!--check:light_brightness_not_zero-->
3. 检查灯罩内侧与导光板是否积尘，积尘会明显降低透光率。<!--manual-->
4. 确认灯具使用年限，LED 灯板长期使用后存在自然光衰。<!--manual-->

## 频繁自动关闭

1. 确认灯具处于开机状态，排除定时任务或场景已将其关闭。<!--check:device_is_on-->
2. 检查灯体与吊顶之间的散热空间是否被遮挡，过温保护会主动切断输出。<!--manual-->
3. 检查墙面开关与接线端子是否松动，接触不良会造成间歇性断电。<!--manual-->
4. 确认同一回路上是否接有大功率电器，启动瞬间的电压跌落会触发驱动保护。<!--manual-->

## 色温切换无效

色温调节依靠灯板内两组不同色温的 LED 按比例混光，切换后约一秒完成过渡，短暂渐变属于正常表现。若色温始终不变，请先确认当前场景或定时任务没有把色温锁定为固定值，场景设定的优先级高于单次调节；再断电重启一次灯具，让固件重新加载参数。仍然无效多为暖白通道的恒流回路异常，应在断电验电后由专业人员检测灯板，不要自行拆开灯罩。
