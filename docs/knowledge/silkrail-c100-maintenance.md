# SilkRail C100 保养与清洁

## 导轨保养

建议每半年清理一次导轨内的积尘与毛絮，用吸尘器细嘴配合软毛刷即可，清理前先断开主机供电。滑轮干涩发响时在轮轴处点少量硅脂润滑，不要使用黄油或喷雾式润滑油，油膜会粘附粉尘并让同步带打滑。导轨中段明显下垂时增加吊装支架，长期弯曲会造成帘布跑偏与运行阻力增大。

## 帘布清洁

轻度浮尘用吸尘器低吸力配合毛刷刷头沿垂直方向清理即可，不必拆下帘布。需要水洗时先断开主机供电，取下吊环挂钩后按面料标签要求洗涤，自然阴干后再悬挂，遮光涂层面料切勿高温烘干或熨烫。重新悬挂后把吊环沿导轨均分，并确认全部滑轮都已回到轨道内。

## 行程复校

更换帘布长度、移动导轨位置或长时间断电后，建议复校一次开合行程，避免端点记录偏移造成提前停止。复校时保持帘布可自由移动、导轨内无异物，全程不要用手拉动帘布。复校完成后分别执行一次完全打开与完全关闭，确认停止位置与预期一致。
