# GlowSoft L90 故障代码

## E1

E1 表示驱动电源过温保护，灯具会自动降低输出功率或直接熄灭以避免器件损坏。请先关闭墙面开关切断供电，等灯体自然冷却约 20 分钟后重新送电。冷却后仍反复报出该代码，多与吸顶安装面的散热空间不足有关：确认灯体与吊顶之间没有被保温棉、装饰板或杂物覆盖，并适当降低所在房间的环境温度。保护始终不解除时不要拆开灯体自行短接测温元件，应联系售后更换驱动电源。

## E5

E5 表示恒流驱动模块输出异常，LED 灯板得不到稳定的驱动电流，表现为不亮、亮度跳变或明显偏色。请断电后重新送电一次，让驱动模块完成自检。若代码持续存在，通常是驱动电源或灯板已损坏，须由专业人员断电验电后整体更换原厂配件。不要自行换用非原厂驱动，输出参数不匹配会加速光衰并可能引发过热。

## 302

302 表示灯具的无线模块与家庭网关连接超时。此时本地按键与墙面开关仍可正常控制照明，只是远程指令无法下达。请确认网关通电且工作正常，再把灯具断电重启一次以触发重新入网。灯具与网关距离过远或中间有承重墙遮挡时应增加中继设备。反复超时且网络指示灯不闪烁，需联系售后检查无线模块。

## 安全提醒

拆装灯体、检查接线端子或测量驱动电源输出前，必须先关闭墙面开关并断开该回路的断路器，验电确认无电后再操作；高处作业要使用稳固梯具并有人扶持。智能体只能依据说明书给出排查建议，无法确认硬件是否已经修好；驱动电源或灯板是否需要更换，应由专业人员现场检测后判定。
