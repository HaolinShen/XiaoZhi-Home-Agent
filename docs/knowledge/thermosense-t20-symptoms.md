# ThermoSense T20 常见症状排查

## 读数与实际明显偏差

1. 确认传感器电池电量充足，电压偏低会让采样电路的基准漂移，温度读数随之整体偏移。<!--check:device_battery_not_low-->
2. 确认设备处于开机上线状态，离线期间显示的是最后一次成功上报的缓存值，并非当前实测值。<!--check:device_is_on-->
3. 检查安装位置是否处于阳光直射、空调出风口或电器散热口附近，局部热源会让读数系统性偏高。<!--manual-->
4. 核对校准偏移设置是否被误改，将温度与湿度的偏移量恢复为零后静置半小时再比对。<!--manual-->

## 数据长时间不刷新

1. 确认设备仍在开机上线状态，Zigbee 链路断开后面板只会保留上一周期的历史数值。<!--check:device_is_on-->
2. 确认电池电量未偏低，电压不足时设备会自动拉长采样周期以节电，表现为刷新变慢。<!--check:device_battery_not_low-->
3. 检查网关与传感器之间是否新增了金属柜体或镜面隔断，反射与屏蔽会削弱链路质量。<!--manual-->
4. 在网关侧查看该节点的最近入网记录，若长期无心跳请删除节点后重新配网。<!--manual-->

## 湿度读数持续偏高

湿度探头长期处于高湿环境时，感湿膜表面会吸附油烟与粉尘，形成持续偏高的虚假读数。请将设备移至通风干燥处静置一至两天观察是否回落；若仍不回落，说明感湿膜已被污染或结露，需按保养章节做干燥恢复处理。切勿用水或酒精直接冲洗探头，液体会永久破坏感湿膜的校准特性。安装在浴室、厨房等高湿场所时，应避开正对水汽的位置。
