# GuardLock D3 保养与清洁

## 清洁周期

建议每月用干燥软布擦拭一次指纹采集头与触摸键盘，油污明显时以微湿软布轻拭后立即擦干，切勿喷洒酒精、清洁剂或用水冲淋，液体渗入面板会腐蚀电路。每季度检查一次电池仓有无渗液与锈迹，并核对门锁时间与开锁记录是否正常。

## 电池更换

面板提示电量偏低或显示低压代码时应及时更换。取下电池仓盖，整组换上同品牌同型号的碱性电池，严禁新旧混用、不同品牌混装或改用充电电池，电压不匹配会导致电机驱动无力。装入前核对正负极方向与仓内标识一致，装好后测试一次指纹与密码开锁。长期外出前建议先换新电池并随身携带机械钥匙。

## 机械部件润滑与虚位检查

每半年检查一次锁体运转：手动旋钮开合数次，感受离合器结合是否顺畅、把手虚位是否变大。斜舌与主锁舌可涂少量石墨粉或专用锁具润滑脂，切勿使用食用油或普通润滑油，油脂积尘后会加剧卡涩。若锁舌回弹迟滞、锁点与锁孔错位或虚位明显增大，应请售后调整门扇合页与锁孔位置，不要强行拧动把手。
