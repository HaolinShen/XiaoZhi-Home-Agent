# FrostLine AC310 保养与清洁

## 滤网清洗周期

在日常使用强度下建议每两周清洗一次滤网，制冷季高频使用时应缩短至每周一次。清洗前须先关机并断开电源，掀开面板后水平抽出滤网，用不超过体温的清水配中性洗涤剂冲洗背面，再置于阴凉处彻底晾干。切勿用热水浸泡、硬毛刷刷洗或直接暴晒，滤网骨架受热会变形而无法回位。滤网未干透就装回会滋生霉菌并加重异味。

## 冷凝水管检查

每个制冷季开始前应检查一次冷凝水管。断电后确认管路自室内机接水盘起全程保持向下坡度，无上翘、折弯或被家具、地板压迫的段落；管末端应位于通风处且高度低于接水盘。可从检修口缓慢注入少量清水观察排出是否顺畅，排出迟缓说明管内有泥沙或絮状堵塞，需拆下末端接头疏通。接水盘边缘的黏滑积垢可用软布擦净。

## 蒸发器与室外机维护

蒸发器盘管翅片每年宜清理一次。断电后用软毛刷顺翅片方向轻扫浮尘，切勿逆向或横向用力，翅片倒伏会永久降低换热效率；不要向盘管直接喷水，电控盒受潮存在漏电风险。室外机应保持四周留有散热空间，及时清除堆积的落叶、飞絮与遮挡物。涉及拆卸外壳、接触电气部件或补充制冷剂的作业，必须由持证专业人员完成。
