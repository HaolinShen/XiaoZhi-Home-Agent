# QuietTrack C60 常见症状排查

## 运行噪音偏大

1. 确认主机处于通电开机状态，未通电时的异响与电机无关。<!--check:device_is_on-->
2. 检查导轨内是否积尘，粉尘进入滑轮会产生持续摩擦声。<!--manual-->
3. 检查同步带张力，过松会打滑异响，过紧会加剧导轨磨损。<!--manual-->
4. 检查吊装支架与减振垫是否松动老化，装配松动会放大振动。<!--manual-->

## 无法完全闭合

1. 确认主机处于通电开机状态，断电时窗帘停在原位不动。<!--check:device_is_on-->
2. 确认窗帘是否已经处于完全关闭位置，避免把到位状态误判为故障。<!--check:curtain_not_fully_closed-->
3. 检查两侧布面搭接处有无异物或纱帘缠绕。<!--manual-->
4. 重新确认闭合端点，端点记录偏内会让窗帘提前停止。<!--manual-->

## 定时开合时刻偏移

定时开合依据主机内部时钟执行，长时间断电后时钟需与网关重新同步，因此偶发几分钟的偏移可先通过重新联网校时消除。若偏移持续扩大，请确认没有同时存在多条时间相近的例程或场景，重复触发会让窗帘反复启停，表现上很像时间不准。日出日落联动模式下的开合时刻随季节自然变化，属于设定本身的行为而非故障。始终不动作时先检查主机供电与网络连接。
