# Project instructions

## Python environment

- Always use the existing Conda environment named `langgraph` for this project.
- On this machine, its Python executable is `F:\Software\Anaconda\envs\langgraph\python.exe`.
- Run tests and Python commands through that environment. Do not use `uv run`, create a `.venv`, or create another virtual environment.
- Do not install, remove, or upgrade packages in the environment unless the user explicitly requests it.
